# SIR-CDR 实现状态与后续实验方案

## 1. 当前结论

当前版本已完成可运行的跨域推荐训练、验证、测试闭环，但尚未完整实现最初设计中的双结构图注入和生成式商品检索。应将现有结果记录为“文本语义与序列编码驱动的隐式推理推荐基线”。接口可以运行、损失可以下降，与模块有效性得到实验支持是两件事。

## 2. 已运行的数据路径

商品文本经过本地 Qwen3-Embedding-8B，以 MRL 方式得到归一化 768 维向量。领域自适应编码器输出 128 维隐向量，再使用四级独立残差 K-means 码本生成 Semantic ID。正式推荐模型冻结这些导出产物，通过可训练投影融合连续隐向量和码字重构向量。

源域与目标域历史分别经过 GRU，得到序列表示。用户表示分解模块和门控隐式推理模块生成共享、私有隐状态；前缀模块把这些状态转换为解码器条件。CPF 在训练中预测商品表示，其预测向量也用于全目标域检索。

训练同时优化 Semantic ID 自回归交叉熵、全目标域检索交叉熵、CPF 及分离正则。验证选取最佳 checkpoint，独立测试脚本计算排名指标。原始商品 ID 仅用于索引和标签，Semantic ID 是文本派生的离散语义表示，二者不可混称。

## 3. 隐式推理的实现范围

UserImplicitReasoner 已包含初始化状态、读门、写门、遗忘门、候选状态更新、LayerNorm，以及共享/私有输出头。正式模型默认执行三步连续隐状态迭代。这是可训练的门控隐状态计算，不输出自然语言推理链，也没有调用大语言模型执行推理。

目前尚无“移除推理”“单步推理”“多步推理”的控制实验，因此不能据现有指标宣称隐式推理优于普通 GRU。共享与私有表示的名称也不自动证明它们已经学到预期的领域分工。

## 4. 推荐生成的实现范围

AutoregressiveSemanticDecoder 已实现 GRU 自回归解码、BOS/EOS 与 Semantic ID 监督。训练使用 teacher forcing。正式评测先通过 CPF 查询向量扫描完整目标域目录，再对检索得到的候选商品已知 Semantic ID 计算条件序列对数概率，并与检索分数融合。

因此当前是“全目录检索 + 生成概率重排”，不是“自由生成 Semantic ID + 反查商品”的完整生成式检索路径。候选池以外的商品不会被生成模块找回。没有随机负采样并不意味着所有商品都计算了生成概率。

原型中存在 beam search 和 ItemTokenIndex，但正式推荐脚本没有调用它们。原型的共享码本和多模态/ID 特征接口也不能直接替代正式文本流程。

## 5. 尚待补全的部分

| 部分 | 当前状态 | 后续工作 |
|---|---|---|
| 共享/领域私有图 | 正式模型未接入 | 从训练交互构建稀疏图，并明确跨域边定义 |
| 双结构注入 | 当前通过序列表示和前缀传递信息 | 接入图传播结果和历史掩码，明确共享/私有信号来源 |
| 生成式检索 | 当前只计算候选序列概率 | 增加目标目录约束的逐级生成、beam search 和同码商品处理 |
| CPF | 已接入预测辅助损失和检索查询 | 消融辅助损失与检索头作用；不宣称已有闭环反复反馈推理 |
| 领域分离正则 | 当前分离项比较 private 与混合 context | 审核是否应比较源域私有信号，独立变更并重新训练 |
| 历史排除 | 当前只排除截断后的目标历史 | 保留完整已见集合，与编码输入截断分离，并统一全部对比方法 |
| 论文证据 | 一次划分、一个种子、一个域对 | 加入受控消融、多个种子、同协议基线和更多域对 |

图模块需使用稀疏邻接/边索引；当前原型的稠密邻接不宜直接扩展到 26,101 个物品。图只使用允许的训练信息，不能从验证/测试标签构图。若论文声称严格按时间预测，还需审查全局图的时间信息边界。

## 6. 后续实验顺序

第一阶段：完成 validation_reranking_sweep.md 中的候选数与融合权重对比。固定最佳 checkpoint、数据和历史屏蔽协议，候选数为 200/500/1000，生成权重为 0/0.5/1/2，按验证集 NDCG@10 比较。该阶段属于推理设置诊断，不需要训练。

第二阶段：完善可切换的消融接口。先固定其余训练目标与评测设置，对比是否执行迭代隐式推理、是否使用 Semantic ID 特征、是否使用 CPF 辅助损失。移除 CPF 辅助损失时保留检索查询头，避免同时移除召回路径造成混淆。目标域单域基线单独定义，不把输入置零等同于严谨的单域模型。

第三阶段：在验证集上对比学习率 0.001 与 0.0003，再独立评估学习率衰减和正则化。按受控实验逐项修改；训练上限与早停相结合，不因为训练损失下降就增加轮次。

第四阶段：接入训练图和双结构注入，以序列基线作为对照。新增的图与历史排除协议须单独版本化，不能把协议变化造成的指标变化归因于模型提升。

第五阶段：实现目录约束的生成式检索。每步只允许目标目录中合法前缀的下一 token，处理共享 Semantic ID 的多个商品，去重并使用不依赖真实标签的同码排序。与现有检索重排路径分开报告召回、精度和耗时。

所有调参依据验证集，保留当前测试结果作为已公开的初始基线记录。后续报告需如实说明已进行的测试与模型选择过程，不把反复观察过的测试集描述为全新未接触的测试集。
